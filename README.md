# Jogo Mario

## Descrição
Projeto desenvolvido como atividade prática para exercitar conceitos de desenvolvimento web e fluxo de trabalho com Git e GitHub. Trata-se de uma recriação simplificada da mecânica do clássico jogo Super Mario (Mario Jump), onde o jogador pula sobre obstáculos para pontuar e se manter no jogo.

## Objetivo
O objetivo deste projeto é aplicar boas práticas de versionamento de software em equipe utilizando Git e GitHub, incluindo a organização e estruturação de pastas de projetos reais, gerenciamento de branches (`main` e `dev`), realização de commits semânticos incrementais e integração contínua via merge.

## Tecnologias
- HTML5
- CSS3 (Animações e Keyframes)
- JavaScript (Manipulação de DOM e lógica de colisão)

## Instalação
Clone o repositório em sua máquina:
```bash
git clone <URL_DO_REPOSITORIO>
cd jogoMario
```

Caso queira navegar até a pasta da aplicação front-end:
```bash
cd frontend
```

## Execução
Como o front-end é estático, você pode executá-lo diretamente abrindo o arquivo `frontend/index.html` em qualquer navegador web moderno:

1. Navegue até o diretório `frontend/`:
   ```bash
   cd frontend
   ```
2. Abra o arquivo `index.html` no seu navegador:
   - No Windows (PowerShell/CMD):
     ```bash
     start index.html
     ```
   - Ou utilize extensões como o **Live Server** no VS Code.
